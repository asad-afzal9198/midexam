📚 Student Task Manager – User Manual

📌 Project Title

Student Task Manager Web Application

🚀 Overview

The Student Task Manager is a responsive web application built using HTML, CSS, and JavaScript.

It allows users to efficiently manage academic tasks by adding, deleting, filtering, and sorting them in a clean and interactive interface.

🎯 Project Objective

This project is designed to:

•	Improve task management for students 

•	Demonstrate front-end development skills 

•	Practice DOM manipulation and API integration 

•	Implement interactive UI features like dark mode 

✨ Key Features

➕ Add Tasks

Users can add tasks by entering:

•	Task Name 

•	Subject 

•	Due Date 

All tasks are dynamically displayed in a table.

🗑️ Delete Tasks

Each task includes a Delete button that removes it instantly from the list.

🔍 Filter Tasks

Users can filter tasks based on subject selection:

•	All Subjects 

•	Specific subject (e.g., Math, English, CS) 

📅 Sort Tasks

Tasks can be sorted by due date (ascending order) for better organization.

🌐 API Integration

The project fetches sample data from an external API:

•	Source: JSONPlaceholder 

🌙 Dark Mode

A built-in theme toggle allows switching between:

•	Light Mode ☀️ 

•	Dark Mode 🌙 

Improves user experience and readability.
